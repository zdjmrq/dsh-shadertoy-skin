# 核心修复与实装验证 · 2026-10-28

开发分支：`fix/playback-interaction-settings`。DSH desktop profile 原本使用工作区链接，直接验证实际 Host、Client 与 Electron 窗口。

## 修复

1. 画面默认开启自动循环。识别明确的结束淡出或 `// @duration N`；没有明确时长时，每秒两次在 GPU 缩小画面后读取 1 KB，确认经历动画后停止变化再重播。重播同时重置 `iTime`、`iTimeDelta` 和 `iFrame`。持续动画和初始静态作品保持播放；手动周期仍可选。
2. 音乐独立运行。自动识别结束淡出或有声后的持续静音，支持循环和只播一次。有限时长的最后一个采样块精确截断，避免越过边界。新学到的静音结束点从采样零开始重放，避免取模跳过开头。
3. 背景只接受从空白开始的主指针左键拖动。输入、普通 `user-select:auto` 回复文本、代码、菜单、拖动控件及滚动条优先交给 DSH。选择出现、离开窗口、进入 iframe、取消、丢失焦点或按键状态异常均释放 `iMouse`；保留按下锚点，修正零坐标符号问题。事件监听不阻止默认操作、不截获指针。
4. 字号原生下拉列表使用明确的文字、实心底色和对应 `color-scheme`，修复透明 iframe 中白底白字。
5. 界面默认半透明。界面启用、不透明度、透明档、模糊、分辨率、帧率、音量与静音全局记忆；亮度、速度及播放策略随作品保存。兼容原 v1/v2 文件，沿用当前作品已保存的全局选择。
6. 保存保持串行、ETag 防覆盖与原子写入。离页补存，小请求使用 keepalive，并记录待保存快照，在磁盘版本仍匹配时恢复；磁盘已经更新时不覆盖它。读取失败保留现有客户端状态。
7. 修复旧的 renderer init 确认迟到时把设置页切回旧作品的竞态；参数更新使更早的状态读取失效。
8. 透明度自愈改为检查实际 token 值，并在启动结束后继续观察 body style，修复页面/主题重新写入不透明底色的情况。用 rAF 合并修复，避开同步主题递归。

## 边界

任意 GLSL 没有统一的播放结束事件，自动识别不是完整的程序语义分析。长暂停、极慢/局部变化和音乐中间长静音可能误判，可关闭画面循环或指定周期/音乐时长。Buffer A–D 与纹理输入仍不支持，导入时延续现有明确报错策略。旧配置明确关闭的循环或选择的不透明档会保留；默认半透明应用于没有显式选择的配置。
