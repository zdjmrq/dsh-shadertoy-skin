# 0.4.4 变更与验证

- 单个「预览并交互」按钮显式启用背景键鼠；Esc、Tab、系统修饰键、失焦、切回 DSH 输入区、切作品、渲染错误、设置页关闭/重载均释放输入并退出。不记忆交互状态；独立预览保持可用。
- 交互消息携带会话标识，快速进入/退出/重进时，旧退出回执不能关闭新会话，旧键鼠消息不能混入新会话。
- 十档有规律的渲染质量：25%、37.5%、50%、62.5%、75%、87.5%、100%、125%、150%、200%，显示名称与实际像素；旧倍率只保留用户当前选中的旧值，不悄悄复原。
- 新增 120 fps。默认仍 100% / 30 fps，其余默认值不变。
- 三处通道输入统一分组、用途说明和连接计数，默认收起；保留 Buffer、图片、字体、噪声、城市示例图和键盘。修复无 Buffer 的粘贴项目无法配置通道的问题。
- 背景库搜索/筛选维持移除。失焦降帧、每作品性能配置、音乐手动周期联动、截图导出、URL 导入均未加入。
- 插件性能复查后移除键盘通道空闲帧中多余的扫描、清零和临时视图分配，重复按下/释放不再触发无效 GPU 上传；真实 WebGL 回归确认连续 120 个空闲帧无清零/上传，一帧按下脉冲、切换位和退出释放语义不变。设置页防抖、纹理缓存、音频预调度和 Worker 边界继续保留，未引入改变默认体验的性能策略。
- 延续此前 main 上的审查修复：设置页并行加载与超时、保存错误正文截止时间、导入 ID 校验、音画联播边界和静音尾段、图片解码尺寸限制与方向修复。

## 验证范围

`npm test`（302 项包检查、TS 7.0.2 strict checkJs、Host、项目格式），以及受影响的 renderer / ui / interaction / core / worker / editor / multi / project 浏览器套件。新增 interaction 纳入 CI 与发布前共用的 15 套件清单。

交互回归使用实际键盘、鼠标、焦点移动和面板重载，最终读回 Worker 中键盘纹理着色器的像素，确认按下/释放与普通 DSH 输入隔离；另覆盖快速三连切换、分组键盘通道粘贴导入、旧倍率保存，以及 120 fps 选项。

实装及发布的最终结果、备份与逐文件校验证据存放在忽略目录 `.tmp-validation/`，不随 npm 包发布。发布使用 GitHub Actions OIDC，包仍为 50 个文件，未添加运行时依赖或构建步骤。
