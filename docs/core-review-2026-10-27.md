# 核心功能审查 · 2026-10-27

审查对象：本地 / GitHub / npm 的 0.2.4。审查与修复限于插件代码，不修改用户 DSH 配置。

| 问题 | 影响 | 修复 |
|---|---|---|
| 初始化次数在所有作品间累计 | 切换几次后 `sendInit()` 永久提前返回，作品切换失效 | 每次切换重置计数；异步加载使用请求序号，丢弃旧响应 |
| 全部 PUT 共用 `shader-skin.json.tmp` | 并发写入互相覆盖或 rename 失败 | Host 串行原子替换、每次使用独立临时文件；面板也串行保存 |
| 保存返回 false 后继续运行成功流程 | 失败仍显示已保存、产生未落盘副本，或加载错误背景 | 检查持久化结果，失败回退选择/删除/副本并保留草稿，可重试 |
| JSON 把第一个非 Sound pass 当 Image | Common 或 Buffer 排在前面时主代码取错 | 显式提取 Image；Common 合并到 Image 与 Sound；拒绝未支持的 Buffer、Cubemap 与纹理依赖 |
| 切换页签重新加载代码 | 未保存修改被静默覆盖 | 会话内按作品保存草稿；只有“放弃修改”显式丢弃；显示未保存标记 |
| 代码编译失败先清空旧 program | 一次编辑错误让背景黑屏，并遗失旧 program 的引用 | 成功编译后才替换 program；失败报告错误并继续绘制原画面 |
| 音乐使用生产时间轴判断结束 | 前瞻调度的最后一段音符被提前 stop | 等待最后已调度音频播放完毕；隐藏/暂停时不启动调度 |

另存内置作品时保留来源、许可证和当前作品参数；我的背景列表显示保留的许可证标记。消息接收同时检查 origin 和父窗口来源。

## 验证

- `npm test`：包结构、发布文件和许可检查；真实 HTTP 状态读写、迁移、非法输入、路径越界、24 个并发 PUT。
- `npm run test:renderer`：真实浏览器 WebGL2、ES1 回退、编译诊断、面板、代码保存与页面滚动。保存测试使用临时 DSH_HOME 与真实 Host 路由。
- `npm run test:audio`：mainSound 四种签名相关夹具、非静音样本、音量、只播一次、循环重放。
- `npm run test:panel`：最小 DSH 服务适配器运行真实 client.js + panel.html + player.html，覆盖多次切换、旧响应竞争、保存顺序、失败重试、草稿、Common 与不支持的导入、编译失败后继续渲染。

`npm run preview` 启动相同适配器，使用独立临时配置，供本地预览。适配器只模拟 React/slots/theme 的必要接口，不等同于完整 DSH 客户端；仍建议在正式发布前用真实桌面版检查侧栏注册、窗口缩放与系统音频自动播放权限。多 pass / 纹理输入仍未实现，本次只纠正识别与失败提示。
