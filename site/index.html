01 / YOUR DESKTOP, YOUR PLAYGROUND

不止是壁纸。
背景，也有玩法。

01

捏一座属于你的山

点「预览并交互」，按住鼠标增高，Shift 配合鼠标挖低。山脊和海岸，跟着你的手势变化。

02

把地牢放到桌面上

方向键逐步移动，走向敌人即可攻击。摸鱼也有风险——别像录屏里一样被反杀。

03

玩完，继续好好工作

Esc 返回设置。平时的打字、选中与快捷键，照常交给 DSH。交互状态不会一直记住。

02 / MAKE IT YOURS

一段代码，
换一张桌面。

内置作品是起点。一两百行画面代码就可能画出一扇雨窗、一片海；Sound 代码还能实时合成音乐。导入喜欢的作品，也可以从零写自己的。

一个编辑区，多个文件标签。改完「保存并运行」，画面就会回答你。

void mainImage(out vec4 color,
               in vec2 pixel) {
  vec2 uv = pixel / iResolution.xy;
  float t = iTime;

  color = vec4(
    0.5 + 0.5 * cos(t + uv.xyx
      + vec3(0.0, 2.0, 4.0)), 1.0);
}

01 / 桌面版安装

复制这一行，就能开始。

dsh plugin --profile desktop add dsh-shadertoy-skin

已上架 dshmarket 插件市场，可以搜索 dsh-shadertoy-skin 安装；也可以在 DSH「插件 → 添加插件」中填包名。

  1. 安装后，完全退出并重新启动 DSH。
  2. 左栏打开「Shader 背景」，选择作品。
  3. 需要玩一会儿？点「预览并交互」。
