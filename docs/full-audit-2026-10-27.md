# 原生配色、透明表面与插件全面审查

日期：2026-10-27。实验分支：`codex/experiment-native-ui`。界面分支 `codex/native-ui` 与修复分支 `codex/audit-hardening` 分别开发，合入本实验分支。原 `main` 保持 `1aec852`，未合并实验改动，未发布 npm。

## 设置界面

读取本机 DSH 安装包的主题实现后，采用其主要中性色：浅色 `#fff`，深色页面 `#151517`、卡片 `#232324`、字段 `#1b1b1c`。按钮、开关、滑块和焦点均以黑白灰表达状态，语义错误仍用红色。

删除页头英文小标、介绍文案、分组说明、参数下方长段说明、重复选择数值。保留必要的名称、单位、代码状态和错误信息。自动保存提示改为不影响排版的状态浮层，避免控件在操作中上下移动。Image / Sound 的专注编辑、行号、字号、换行和高度记忆继续保留。

## 透明度策略

| 表面 | 半透明 / 透明档的策略 |
|---|---|
| 主界面外壳 | 背景与遮罩合成一次，避免多层遮罩把画面压黑 |
| 普通卡片 | 基础不透明度分别为 72% / 38%；低遮罩时根据最亮/最暗背景提高安全下限 |
| 聊天输入框 | 至少 85% 不透明 |
| Markdown 代码块 | 至少 84% 不透明 |
| 菜单、选择器、分组菜单头 | 97% 不透明，保留清楚的文字与边界 |
| 设置、确认等关键对话框 | 100% 不透明；实机发现 98% 仍有背后文字重影后进一步调整 |
| 插件自身设置页、背景库、代码工作区与专注编辑 | 跟随不透明 / 半透明 / 透明选择；沿用普通卡片的安全下限，代码框内部不重复叠加底色，底部操作栏至少 85% 不透明 |

只覆盖语义背景 token，不再覆盖静态中性色板。静态色板也会被原生文字、图标使用，全局改写它可能把前景文字一起变透明。原生遮罩与语义颜色保持各自职责。

截图：[深色设置](verify/ui-refresh/settings-dark.png)、[浅色设置](verify/ui-refresh/settings-light.png)、[代码页](verify/ui-refresh/editor-dark.png)。透明度回归截图见 [surface-audit](verify/surface-audit/)；这些截图由真实插件配合最小 DSH 服务适配器和语义表面夹具生成，桌面端另做人工验收。

## 本轮问题与处理

| 级别 | 问题 | 处理 |
|---|---|---|
| P1 | 初次读取配置失败后以空库继续保存，可能覆盖用户背景库 | 读取失败禁止写入，提供重新加载；损坏文件原样保留 |
| P1 | 两个设置窗口读取同一旧快照，后保存者覆盖先保存者 | 状态 GET/PUT 增加 ETag / If-Match，旧修订返回 409，不静默覆盖 |
| P1 | 全局改写静态中性色，可能影响前景文字/图标 | 删除静态色板覆盖，仅修改语义表面 |
| P2 | 背景关闭后启动/调参仍可能重新透明化原生界面 | 关闭状态统一清除样式与 token；后续调参也不重加 |
| P2 | 深浅模式切换时播放器保留上一主题遮罩 | 主题变化同步发送当前主题的实际 tint 参数；验证 GPU uniform |
| P2 | 透明档的菜单底色过淡、浅色对话框透出背后代码 | 菜单提高到 97%；关键对话框完全不透明 |
| P2 | 未保存代码只在内存中，刷新会丢失 | 当前浏览会话用 sessionStorage 恢复草稿，显式放弃时清除 |
| P2 | 保存代码期间切换作品，迟到结果可能作用于错误作品 | 保存结果检查当前作品与已加载编辑对象，避免错误应用 |
| P2 | 自有 JSON 的 Sound 字段、Image/Sound 混合 GLSL 导入时丢音频 | 两种格式均保留声音；错误 Sound 不再静默丢弃 |
| P2 | 只比较原始代码长度，JSON 转义后请求可能超过 Host 上限 | 按 UTF-8 代码字节和完整序列化请求双重预检，保留原输入 |
| P2 | 数值、重复作品 ID 缺乏 Host 验证 | 按默认参数范围校验，拒绝重复 ID；损坏结构不作为有效状态加载 |
| P2 | 图形上下文丢失后背景不能恢复 | 处理 context lost/restored；恢复后重载播放器并重新初始化当前作品 |
| P2 | 固定假设 GPU 最大分辨率 | 同时读取设备纹理和 viewport 限制，最高仍限制为 8192 |
| P2 | 画面速度改变只移动音频块起点，可能重复/跳过声音；速度零导致重复块 | 速度明确只控制画面，音频使用连续独立时间轴 |
| P2 | 全量参数消息被误判为音乐模式变化，可能再次截断尾段 | 只在模式/时长实际变化时重调度 |
| P2 | 切换带音作品时先启动声音，再应用音量/静音 | 初始化先应用参数，避免短暂使用旧音量 |
| P2 | 本地预设符号链接可能绕过目录边界 | 解析真实路径后二次检查；目录 junction 越界有回归测试 |
| P3 | 插件卸载发生在异步启动期间，晚到任务可能重建背景 | 增加 disposed 检查，阻止已释放插件继续启动 |
| P3 | 声音编译失败提示不足、重试按钮没有重试代码保存 | 声音错误在设置和代码页展示；重试指向当前实际保存操作 |
| P3 | 每帧创建未使用的通道数组 | 复用零值 uniform 数组 |

上一轮修复的初始化次数耗尽、请求竞争、原子保存临时文件竞争、Common pass 识别、页签切换草稿丢失、编译失败黑屏、音频尾段提前停止均继续保留，并运行原回归测试。
