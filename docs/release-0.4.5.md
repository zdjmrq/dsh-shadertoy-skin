# 0.4.5 — 新增三个多文件内置项目

- 新增 **诡异的线条 / 造山 / 地牢游戏**，按原文件夹名展示；内置库从 12 项增至 15 项。
- 分别接好 Common、各 Buffer、键盘、字体和离线噪声输入，保留浮点状态。
- 造山：鼠标按住造山，Shift 按住挖低，Backspace 重置，Enter 切换侵蚀。
- 地牢：方向键逐步移动，走向敌人攻击，撞墙跳过一回合；原作品需松开再按下一步。
- 诡异的线条：空格重置。
- 键盘操作使用既有 **预览并交互**，Esc / Tab / 失焦退出；平时 DSH 输入不转发。
- 补齐 ShaderToy `iFrameRate`，并保证冻结/初始帧不会提供零值。
- 修复退化线段与笔刷中心除零、无侵蚀时的材质数据除零，以及内存限额下的地形采样/地牢画面合成尺寸。
- 保留第三方署名和 CC BY-NC-SA 3.0 项目说明；造山侵蚀算法另保留 MPL 2.0，完整许可随包提供。
- 新增真实 WebGL 回归套件：画面、Buffer 数量/内存、造山增高/降低/重置、地牢实际移动及 1080p 合成；CI/发版共同运行。

安装后请完全退出并重新启动 DSH。原有背景选择、默认参数和个人项目不变。
造山、线条反馈等项目负载较高，可按设备选择 50%–75% 分辨率。
