# 代码审查报告（2026-10-29）

审查对象：`dsh-shadertoy-skin` **0.4.3**（`main` @ `bafcfb0`）。

范围：Host half、client half、WebGL2 渲染器与 Worker、设置页、工具链、CI/CD、README 与文档。
方法：逐文件通读 + 定向检索风险模式 + 全量回归套件复跑（本地 msedge，CI 为 chrome + SwiftShader）。
本报告只记录结论；决策与取舍另见 [`00-决策与方案复核.md`](00-决策与方案复核.md) §9.18。

## 结论

- **确定的缺陷 12 项已全部修复**，每项都有对应回归或可复跑的检查。
- **CI/CD 5 处结构性改进**：语法检查全量化、浏览器套件并行化、`surfaces`/`transparency` 纳入 CI、发布流程改为「先全量验证再发布」、新增独立的 TypeScript 类型检查 job。
- **TypeScript 7 作为纯类型检查器接入**（不重写成 `.ts`、不加构建步骤），详见本节末与决策记录 §9.19。
- **两项产品决策已按用户意见处理**：音乐结束判定做了「图像是否参与」的研究（结论：不参与，见 §9.20 与 [`research/04-audio-image-end.md`](research/04-audio-image-end.md)）；商店截图改为手动维护、不再从演示视频截帧（§9.21）。

### TypeScript 7 类型检查（不是重写）

- 加入 `typescript@7.0.2`（精确版本）与 `@types/node@24`，`tsconfig.json` 用 `allowJs` + `checkJs` + `strict` + `noEmit`，覆盖 `index.js`、`native-dist/project.js`、`pipeline.js`、`textures.js`。
- 包仍然是零构建的纯 `.js`：不产出 `.d.ts`、不改 npm 包内容、不改「改文件刷新即生效」的开发流程。详细取舍见 [`00-决策与方案复核.md` §9.19](00-决策与方案复核.md)。
- `npm run typecheck` 已接入 `npm test` 与 CI；类型化过程中发现并修复了上面第 11 项。

## 二、CI/CD 改动

1. `ci.yml` 语法检查从手写文件清单改为 `git ls-files '*.js' '*.mjs' '*.cjs'` 全量：此前 `tools/inspect-live.mjs` 等从未被检查过，新增脚本也要人工补清单（当时的 `make-market-assets.cjs` 后来也拆成了只生成图标的 `make-icon.cjs`）。
2. 浏览器套件从「一个 job 串行跑 10 个套件（约 13 分钟）」拆成 **12 个并行 job**（`renderer` / `audio` / `panel` / `ui` / `audit` / `core` / `project` / `multi` / `worker` / `editor` / `surfaces` / `transparency`）：失败按套件命名、互不阻塞、单套件超时 15 分钟。
3. 把原先「只在本地跑」的 `test:surfaces`、`test:transparency` 纳入 CI（两者都只用 `browser-harness` + SwiftShader，本机已复跑通过）。
4. `publish.yml`：发布前先并行跑同一批 12 个套件（`verify` matrix），**全部通过**才进入 `publish`；`publish` 只保留 tag/版本校验、`npm test` 与 OIDC `npm publish`。原来的串行套件接近 15 分钟超时线，且与 CI 重复。
5. `docs/PUBLISHING.md` 同步两条流水线的描述与 npm 11/12 `pack --json` 差异说明。
6. 新增 `typecheck` job（`npm ci` + `npm run typecheck`），发布前的 `npm test` 同样包含类型检查。

## 三、核对过、确认没有问题的部分

- **Host half**：路由前缀/方法校验、`resolveInside` + `realpath` 双重边界（含 Windows 大小写归一）、状态 PUT 的串行原子替换、独立临时文件、ETag/If-Match 409、save-id 重放幂等、本地预设列表的符号链接与大小限制、`/state` 损坏时保留原文件。
- **client half**：玻璃 token 只覆盖语义背景 token、不碰静态色板；主题观察器避免 `theme/change` 回环；`tokensIntact` 按值修复；启动自愈（iframe / glass / sidebar / player init）与 safe-mode 逃生阀；鼠标隔离（UI 目标、文本选区、滚动条、拖拽阈值、pointer capture）。
- **渲染器**：ES3 → ES1 回落、uniform 重定义跳过（最多 8 次）、编译错误保留旧 program、`@duration` 与 fade 结束探测、多 pass 的 96 MB/8MP 预算、`EXT_color_buffer_float` 缺失报错、上下文丢失/恢复与 1 分钟熔断、Worker 看门狗与 `transferControlToOffscreen` 隔离。
- **音频**：4096 样本块、16-bit 打包、lookahead/prebuffer、`once` 模式排空尾音、loop 接缝淡入淡出、自动结束探测、静音时跳过合成（未知时长仍合成以探测结束）。
- **项目格式**：`normalizeCode` 的 include 循环/文件名/图片内嵌校验、`sourceFor` 2 MB 展开预算、ShaderToy JSON 的 Common/Buffer/Image/Sound 解析与不支持输入的明确报错。
- **设置页**：自动保存队列、409/413/502 等错误文案、恢复日志与 draft、内置作品「另存为副本」、导出/导入、行号/字号/自动换行/专注编辑/高度持久化、键盘可达的下拉与页签。
- **打包与许可**：`files` 白名单与 `npm pack` 清单一致、第三方预设的署名/许可/来源校验、`docs/` `tools/` `assets/` `screenshots.json` 不进包、OIDC provenance 链路已验证。

## 四、产品决策与后续选项（本轮已处理）

1. **英文 UI / i18n**：保持中文（用户已明确不需要英文界面）。`locale/*.json` 只作为插件管理器展示资源保留。
2. **Awesome DSH 列表的条目描述**：暂不更新（用户明确不用管）。
3. **是否发版**：本轮先只合并 `main`；全部改动完成后再由用户决定是否发 0.4.4（版本号与 npm 均未动）。
4. **音乐结束判定**：已研究，结论是**图像不参与**（`take-on-me` 音乐 180 s 结束而图像还有 29 s，是硬反例）；若之后有「间奏被截断」反馈，优先做音频包络置信度。详见 [`research/04-audio-image-end.md`](research/04-audio-image-end.md) 与决策记录 §9.20。
5. **`init` / `params` 乱序**：已在 `fix/init-revision` 分支修复（client 打 revision、控制器按流丢弃旧值），并加了 `test:worker` 回归；不再是遗留问题。
6. **商店截图**：不再自动从演示视频截帧，改成手动维护；`tools/make-market-assets.cjs` 删除，只保留图标生成 `tools/make-icon.cjs`，规范写在 [`market/README.md`](market/README.md)。`docs/market/*.png` 与 `screenshots.json` 的既有文件保留，用户用自己截的图覆盖同名文件即可。
