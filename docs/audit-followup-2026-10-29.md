## 仍需取舍的方向

| 方向 | 判断与建议 |
|---|---|
| 背景键盘交互 | 暂不转发。仅按“指针不在 UI 上”判断，仍可能把输入框中的快捷键/打字交给背景。若做，建议独立、显式的交互模式，并支持一键退出 |
| 失焦省电 | 有价值，但副屏观看背景的人会受影响。建议做可选项，默认保持现状；不静默降低用户已选帧率 |
| 每作品 fps/分辨率 | 重作品有价值，建议后续加入“继承全局/独立设置”，并设计全局调节与作品覆盖的优先级，避免看似设置失效 |
| 手动周期同步音乐 | 本轮明确保留手动周期仅控制画面，且在 UI 说明。强制音乐同周期会截断音乐；若需要，建议新增显式选项 |
| PNG 导出 | 可做。优先从独立预览导出原始背景，避免把 DSH 聊天/个人信息也截进去；本轮未加入 |
| URL 导入 ShaderToy | 仍不做。需要单独确定网络获取、资源支持与错误处理范围 |

现有核心保护仍是 Worker 隔离/看门狗、GPU 恢复熔断、有限资源预算、ETag 并发控制和原子落盘；这些约束不能保证任何 GPU 驱动或任意 shader 永不异常。本轮已覆盖明确可复现的问题，没有把需要产品取舍的功能混入默认交互。
